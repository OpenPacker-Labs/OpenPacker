OpenPacker

Open Package Manager (opm / opmx) plus a PREX control plane for multi-ecosystem package identity, locks, proofs, and digests. One project file, one lock, one verified store — across npm, Cargo, NuGet, PyPI, Go, and Maven.

What it does

  • opm init / opm import --native / opm add / opm install / opm sync / opm ci — project lifecycle with no-follow, handle-relative writes and environment generations you can roll back.
  • Every artifact is verified against the digest its registry published; tampered stores rebuild from verified archives or fail closed.
  • PREX: content-addressed identity, digest-pinned protocol goldens, receipts, and offline-first conformance gates.
